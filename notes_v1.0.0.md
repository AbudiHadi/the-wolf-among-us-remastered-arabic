## Arabic Translation — v1.0.0

**Made for Steam build 25961017.**

> ⚠️ A game update restores the original files; reinstall this release after an update.

### ✨ What's new
- First release: a complete Arabic translation of every text in all five episodes — dialogue and subtitles, dialogue choices, menus and settings, the Book of Fables, and the Extras (achievements, galleries, deleted scenes).
- Right-to-left Arabic in the Almarai typeface on every screen, with long paragraphs in correct top-to-bottom order.
- The translation is a joint effort of AI and human review: every line was translated, then independently reviewed before approval.
- All engine work (fonts, right-to-left rendering, build and install tooling) by Lexara (formerly RTL Forge).
- Manual install only: two files are added to the game's Archives folder, nothing original is replaced; Steam's file verification leaves them in place.
- The Arabic text is bound to the translation's fonts: copying or editing it outside this package gives unreadable text.

### 📦 Install
1. Close the game and back up the original files (listed in the README).
2. Copy the translation files from the zip into the game folder and choose **Replace**.
3. In the game: لا حاجة لتغيير أي إعداد: العربية تظهر مكان الإنجليزية مباشرة
